# SatQuery local performance benchmark

This run measures load, first-request, warm specialist, and end-to-end latency. It is not an accuracy benchmark.

- grounding: first 2429.8 ms; warm mean 1079.7 ms
- sar_single_image: first 15.9 ms; warm mean 6.9 ms
- optical_sar: first 192.4 ms; warm mean 24.0 ms
- bitemporal: first 758.2 ms; warm mean 452.2 ms
